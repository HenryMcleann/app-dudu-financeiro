Este é o repositório do **Dudu**, um protótipo de aplicativo de controle de gastos e companheirismo virtual focado em privacidade, segurança e alta retenção de usuários através de gamificação por afeto.

Idealizado e desenvolvido por **Henrique**, o sistema quebra o padrão frio das IAs corporativas tradicionais ao adotar uma personalidade expressiva baseada em regionalismo e sotaques. O Dudu age como um amigo próximo, pai ou mãe: elogia conquistas, dá broncas bem-humoradas em gastos desnecessários e cria uma conexão humana real com o usuário.

## 🚀 Funcionalidades Principais (Arquitetura do Sistema)

*   **🧠 Cofre de Memória Criptografada (Permanente Oculta):** Funcionalidade avançada baseada em engenharia de IA. Caso o usuário queira desabafar dados confidenciais ou registrar segredos, o aplicativo utiliza a biblioteca `base64` para simular uma criptografia de ponta a ponta. Os dados brutos desaparecem da tela na mesma hora, mas permanecem em um histórico "frio" ilegível para humanos no celular. O Dudu consegue ler esse cofre de forma segura para lembrar de conversas anteriores e manter o vínculo afetivo.
*   **🔒 Privacidade por Design (Blindagem de Dados):** O aplicativo não solicita permissões abusivas do sistema operacional. Ele não lê contatos, redes sociais, WhatsApp ou dados bancários. Funciona como uma caixa preta onde as conversas só avançam até onde o usuário permite.
*   **📸 Trava de Privacidade via Biometria Nativa:** Caso o celular seja emprestado, o chat bloqueia automaticamente em segundo plano. O acesso às mensagens só é liberado através de reconhecimento facial (Face ID) ou digital (Touch ID).
*   **💥 Modo Segredo Autodestrutivo:** Quando o usuário inicia uma frase com a palavra "segredo", a inteligência processa a informação na memória RAM temporária e executa a destruição imediata dos dados (`del`), deixando zero rastros físicos na tela do aparelho.
*   **🗣️ Preferência de Sotaque (Automático por GPS vs Manual):** O usuário tem controle total da experiência. O sistema pode ler a geolocalização (GPS) para se adaptar de forma automática (Nordeste/Sul) ou o usuário pode alternar para o modo Manual, fixando de vez o aconchegante sotaque de Pernambuco/Arcoverde, independentemente de onde estiver viajando.
*   **🔋 Notificações Ativas e Monitoramento de Hardware:** O app monitora os componentes do celular. Se a bateria atingir níveis críticos (<= 5%), o assistente envia notificações "histericamente" preocupadas no balão do celular (*Inline Reply*).
*   **🚨 Protocolo de Emergência de Saúde:** Análise de sentimento em tempo real. Caso termos de risco à saúde física ou mental sejam detectados, o app aciona imediatamente a discagem de emergência (SAMU/Polícia) e envia mensagens automáticas de SOS para os contatos de confiança.

## 🛠️ Tecnologias Utilizadas

*   **Linguagem:** Python 3
*   **Módulos Nativos:** `base64` (Segurança), `random` (Espontaneidade), `time` (Hardware e Delay).
*   **Conceitos Aplicados:** Criptografia Simétrica, Gerenciamento de Memória RAM, Lógica Condicional Avançada, Manipulação Dinâmica de Strings, Mascaramento de Dados e Estruturação de Estado (State Management).
