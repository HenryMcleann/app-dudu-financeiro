# 🤖 App Dudu Financeiro - Assistente Virtual com Inteligência Emocional

Este é o repositório do **Dudu**, um protótipo inovador de aplicativo de controle de gastos e companheirismo virtual focado em privacidade, segurança e alta retenção de usuários através de gamificação por afeto. 

Diferente das IAs tradicionais e corporativas, o Dudu possui uma personalidade expressiva (com foco em regionalismo e sotaques), agindo como um amigo próximo, mãe ou pai. Ele elogia conquistas, dá broncas bem-humoradas em gastos desnecessários e cria uma conexão humana real com o usuário.

## 🚀 Funcionalidades Principais (Arquitetura do Sistema)

*   **🔒 Privacidade por Design (Blindagem de Dados):** O aplicativo não solicita permissões abusivas. Ele não lê contatos, redes sociais, WhatsApp ou dados bancários. Funciona como uma caixa preta onde as conversas só vão até onde o usuário permite.
*   **📸 Trava de Privacidade via Biometria Nativa:** Se o celular for emprestado, o chat bloqueia automaticamente em segundo plano. O acesso às mensagens só é liberado através de reconhecimento facial (Face ID) ou digital (Touch ID).
*   **💥 Modo Segredo Autodestrutivo:** Funcionalidade focada em privacidade extrema. Quando o usuário inicia uma frase com a palavra "segredo", a inteligência processa a informação na memória RAM temporária e executa a destruição imediata dos dados (`del`), deixando zero rastros físicos no aparelho.
*   **🗣️ Inteligência de Sotaques Regionais:** O sistema identifica a geolocalização (GPS) e adapta dinamicamente as gírias do assistente. O modelo atual simula com precisão o sotaque e as expressões do Nordeste (Pernambuco/Arcoverde).
*   **🔋 Notificações Ativas e Monitoramento de Hardware:** O app monitora os componentes do celular. Se a bateria atingir níveis críticos (<= 5%), o assistente envia notificações "histericamente" preocupadas no balão do celular (*Inline Reply*).
*   **🚨 Protocolo de Emergência de Saúde:** Análise de sentimento em tempo real. Caso termos de risco à saúde física ou mental sejam detectados, o app aciona imediatamente a discagem de emergência (SAMU/Polícia) e envia mensagens automáticas de SOS para os contatos de confiança.

## 🛠️ Tecnologias Utilizadas

*   **Linguagem:** Python 3
*   **Conceitos Aplicados:** Gerenciamento de Memória, Lógica Condicional Avançada, Manipulação Dinâmica de Strings, Mascaramento de Dados e Estruturação de Estado (State Management).
